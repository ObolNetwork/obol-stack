# Obol Agent AG-UI Backend

AG-UI backend for Obol Agent with MCP tools integration.

## Setup

```bash
pip install -r requirements.txt
```

## Run

```bash
python agent.py
```

Server runs on `http://localhost:8000` with AG-UI endpoint at `/adk`.

## Frontend Integration

Connect your AG-UI frontend to `http://localhost:8000/adk`.
