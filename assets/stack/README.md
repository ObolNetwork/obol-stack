# Obol Stack icon drafts (unused)

Square catalog/favicon drafts derived from the wordmark's stack mark
(`web/public-storefront/public/obol-stack-logo.svg`) — obol-green (#2fe4ab)
on the bg02 dark token (#111f22). Kept for a possible future stack
sub-brand; NOT currently referenced by code.

The live 402 catalog icon (`x402.ResourceIconURL` in
`internal/x402/bazaar.go`) points at the Obol infinity-loop mark at
https://obol.org/ObolIcon.png (mirrored to obol.org from the
ObolNetwork/obol-org-site repo root). To switch to these drafts later, add
them to that repo (e.g. under `assets/stack/`) and update the constant.

`icon.svg` is the canonical source; PNGs were rendered with sharp at 300dpi.
